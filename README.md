# Projet Luthier - Gestion des Stocks et Configuration de Guitares

Ce projet est un logiciel développé en .NET permettant à un luthier de gérer son stock de composants de guitare et de permettre à ses clients de configurer leur guitare en fonction des composants disponibles. Le logiciel dispose de deux interfaces principales : une pour le luthier pour gérer les stocks, et une autre pour les clients pour personnaliser leurs guitares.

## Fonctionnalités

### Interface du Luthier

* Gestion du stock de composants de guitare (bois, micros, vibratos, etc.)
* Ajout, suppression et modification des composants
* Affichage du stock en temps réel avec des informations détaillées
* Possibilité d'ajouter de nouveaux composants au stock

### Interface Client

* Configuration personnalisée de guitare à partir des composants disponibles
* Choix de composants spécifiques (bois, micros, vibrato, etc.) pour créer la guitare idéale
* Aperçu en temps réel de la guitare configurée
* Possibilité de sauvegarder ou de commander la guitare configurée

## Technologies utilisées

* .NET
* WPF (Windows Presentation Foundation) pour l'interface utilisateur
* Base de données locale pour stocker les informations sur les composants et les configurations de guitare

## Installation

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/AzmogEx/Projet-Luthier.git
   ```

2. Ouvrir le projet avec Visual Studio
3. Restaurer les packages NuGet
4. Lancer l'application depuis Visual Studio

## Utilisation

### Pour le Luthier

1. Ouvrir l'interface du luthier
2. Ajouter ou modifier les composants de guitare dans le stock
3. Suivre l'état du stock en temps réel

### Pour le Client

1. Ouvrir l'interface du client
2. Sélectionner les composants souhaités pour configurer la guitare
3. Visualiser la guitare personnalisée et la sauvegarder ou commander
